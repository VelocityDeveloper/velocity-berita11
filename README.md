Velocity Child Theme Paket Portal Berita 11
=================
[berita11.velocitydeveloper.com](https://berita11.velocitydeveloper.com/)

Child Theme for the Velocity System WordPress theme.

### Required
Theme Velocity versi 2.7.5 keatas. Plugin Kirki **tidak diperlukan** lagi sejak versi 1.1.0 , [Download](https://github.com/VelocityDeveloper/velocity/releases)

### Usage
Simply download the zip and upload the zip (velocity-berita11.zip) under your WordPress dashboard at Appearance > Themes. Or extract and upload via FTP at wp-content/themes/.

## Shortcode

#### Post Widget Shortcode

```php
[vd-post]
```

- category: slug kategory
- limit: jumlah post
- order: order post (ASC/DESC)
- orderby : orderby post (date,meta key)

## Customizer (Tampilan › Sesuaikan › Berita)

- **Warna**: `color_theme` (bawaan #e3093d; bila kosong memakai Primary Color induk).
- **Banner**: `banner_header1`, `banner_single1`, `banner_single2`, `banner_footer` + link masing-masing (`<id>_link`).
- **Sosial Media**: `sosmed_facebook`, `sosmed_instagram`, `sosmed_youtube`, `sosmed_twitter`, `sosmed_tiktok` (kosong = ikon disembunyikan).

Nama setting sama dengan versi Kirki, jadi isian lama tetap terbaca.
